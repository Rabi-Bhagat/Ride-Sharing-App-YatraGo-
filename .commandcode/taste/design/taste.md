# Design

- Dislikes decorative floating overlay widgets on the home screen (e.g. a floating "3D live tracker" pill); prefers that surface be used for a functional, conversational AI assistant that answers user questions and gives suggestions. Confidence: 0.4
- Prefers distinct content sections laid out separately on the page (e.g. scenic routes as their own compact, fitted gallery section) rather than crammed together or toggle-switched inside one container; frames should look professional, with images/visuals fully contained and never cropped. Confidence: 0.5
- Wants UI features to feel interactive and attractive, with explicit motion/transition polish (entry animations, staggered reveals, typing/streaming effects, hover feedback) added to new components rather than shipping static UI; asks for "transition effects" by default when requesting any UI rework. Confidence: 0.7
- Wants both dark and light appearance modes available across the entire app (every page/screen, not just one), with consistent theming so users can pick what feels comfortable. Confidence: 0.6
- Prefers the home page kept lean and focused on core booking/search — large immersive experiences (e.g. the 3D drive simulator) should not be embedded there but live behind the "Explore & 3D" navigation entry. Confidence: 0.5
