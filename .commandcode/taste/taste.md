# Taste

## UX / product behavior
- Search and location inputs must start empty on page load — no pre-filled demo/default places (e.g. don't seed pickup/destination with hardcoded sample locations); users should type and search their own choice. Confidence: 0.65
- New user-facing pages/features should be surfaced as a top-level navbar entry for easy discoverability — not buried inside a dropdown or only reachable via an in-page CTA. Confidence: 0.5
- Wants live widgets driven by real user/ride state rather than static simulated placeholders — e.g. the transit route should track the ride in real time (real GPS/location updates) instead of a hardcoded fake "64 km/h" simulation banner. Confidence: 0.5
